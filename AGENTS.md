# AGENTS.md — `hivemind-websocket-client`

Guidance for AI coding agents (and humans) working in this repository. Read it
fully before making changes. It encodes conventions that are not obvious from the
code and that, if ignored, produce work that will be rejected.

## Repo

`hivemind-websocket-client` (package `hivemind_bus_client`) is the reference
Python client for the HiveMind wire protocol: an authenticated, encrypted
WebSocket client that extends the OVOS bus client, providing `HiveMessageBusClient`
(sync) and `AsyncHiveMessageBusClient` (asyncio). Part of the
[HiveMind](https://github.com/JarbasHiveMind) ecosystem — a protocol for
connecting satellite devices to a hub running
[OpenVoiceOS](https://github.com/OpenVoiceOS). The hub is
[HiveMind-core](https://github.com/JarbasHiveMind/HiveMind-core); protocol
details live in its `docs/protocol.md`. Every satellite package
(`hivemind-mic-satellite`, `HiveMind-voice-relay`, `HiveMind-voice-sat`,
`HiveMind-cli`) builds on this library — a wire-format change here has to stay
compatible with all of them.

## Layout / build / test

- Package module: `hivemind_bus_client/`. Tests live in `tests/` (unit) and
  `tests/e2e/` (live-hub, marked separately — check before adding, do not
  create a second test directory).
- Set up a throwaway environment inside your clone; never touch a shared venv:
  `python3 -m venv .venv && VIRTUAL_ENV=$PWD/.venv uv pip install -e ".[test]" --prerelease=allow`
- Run the suite in the foreground: `python3 -m pytest tests -q` (excludes
  `tests/e2e/` by directory). The `e2e` extra needs a running v3-capable
  (Noise) `hivemind-core` and is installed separately in CI via a git ref
  pinned in the workflow, not declared in `pyproject.toml` — do not try to add
  it as a normal dependency, PyPI rejects direct-URL metadata.
- `uv`, never `pip`. If latest prereleases fail to install or resolve, that is a
  bug to FIX at the source, not to work around with a pin downgrade.

## Tests

- Adversarial by default. A regression test must **fail before the fix and pass
  after** — prove it by reverting only the source (`git apply -R`, never
  `git stash` across worktrees) and watching the test flip.
- Tests must be mutation-proof: gutting the feature must fail the test. A test
  that only asserts a mock was called, without asserting the real behaviour, is
  weak — note it.
- Never skip a test because an optional dependency is missing.
- CI green is permission to review, not to merge. A non-trivial change gets an
  adversarial review before it lands.

## Repo-specific rules

- This library IS the reference implementation of the HiveMind wire protocol.
  Any change to `hivemind_bus_client/protocol.py`, `message.py`,
  `serialization.py`, `encryption.py`, or `noise.py` must stay backward
  compatible with deployed clients and hubs across protocol vintages —
  breaking the wire format here breaks every satellite in the ecosystem, not
  just this repo.
- `HiveMessageBusClient.connect()` and `AsyncHiveMessageBusClient.connect()`
  both accept `handshake_max_retries` and pass it to `wait_for_handshake()`
  (`hivemind_bus_client/client.py:261`, `async_client.py:276`) — never remove
  this bound or make retries unconditionally infinite; an unbounded default
  hangs forever against a stalled or unreachable hub.
- A refused access key is fatal, not retryable: the client closes with
  `AUTH_REJECTED_CLOSE_CODE = 1008` (`client.py:362`) per the
  hivemind-websocket-protocol spec. Do not turn an auth rejection into a
  reconnect loop.
- Node identity (`hivemind_bus_client/identity.py`) persists to
  `JsonConfigXDG("_identity", subfolder="hivemind")`, and the Noise static key
  is derived from the node name stored there. `NodeIdentity` refuses to boot
  from an identity file that exists but fails to parse — never relax
  `_assert_identity_readable()`'s guard, since a silent fallback to an empty
  identity would mint a brand-new static key and make the node look like an
  impostor to every peer that pinned the old one. Reconnect logic must reuse
  the persisted identity/key, never regenerate on its own.
